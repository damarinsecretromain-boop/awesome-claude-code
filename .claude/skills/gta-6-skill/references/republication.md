# Republication TikTok ↔ YouTube Shorts

## Principe
Même moment original, emballage adapté. On publie le **même master** (`master.mp4`, sans
filigrane) sur les deux plateformes, avec deux packs différents.

| | TikTok | YouTube Shorts |
|---|---|---|
| Moment / montage | identique | identique |
| Hook écran | émotion, ton parlé | clair, cohérent avec le titre (peut différer) |
| Texte principal | description courte | titre recherchable (3 propositions) |
| Description | 1 phrase + crédit | contexte + crédit + URL source + CTA |
| Hashtags | 3–5 de niche | 1–3 (affichés au-dessus du titre) |
| CTA | conversation | abonnement / playlist |

## Interdits
- Réutiliser un export avec filigrane d'une plateforme sur l'autre.
- Mentionner l'autre plateforme dans le texte.
- Fusionner les statistiques : chaque plateforme est analysée indépendamment.
- Republier un clip retiré pour droits d'auteur ou violation des règles d'une plateforme.

## Règles des plateformes (à vérifier régulièrement)
- Respect des droits : clipper uniquement avec autorisation (programme de clipping du
  streamer, accord, politique publique) et créditer.
- Contenu « réutilisé » : l'ajout de valeur (montage, sous-titres, hook, contexte) est attendu,
  en particulier pour la monétisation YouTube.
- Musiques : éviter les musiques sous droits ajoutées au montage.
- Divulgation des partenariats rémunérés via les outils de chaque plateforme.

## Faut-il porter un clip sur l'autre plateforme ?
Utiliser `tracker.py report` (diagnostic croisé). Repères :
- **TikTok → Shorts** si : bonne rétention, payoff compréhensible sans son et sans connaître
  le streamer, sujet recherchable (jeu, événement). Réécrire hook/titre en version claire.
- **Shorts → TikTok** si : forte rétention, réaction humaine visible, potentiel de débat.
  Réécrire le hook en version émotionnelle et accélérer la première seconde si besoin.
- Un écart de performance n'invalide pas le moment : tester d'abord un autre hook, titre,
  couverture ou horaire sur la plateforme faible.
